## Linear tracking

Work for this repo is tracked in Linear: team **Command**, project **lessdumb** (https://linear.app/central-lab/project/lessdumb-eba54d7c00f2). Use the Linear MCP tools.

- Before non-trivial work, find the matching issue (`list_issues` with `project: "lessdumb"`) or create one in that project. Move it to In Progress.
- Name the branch with the issue's `gitBranchName` (e.g. `nicocerond/command-12-...`) or put the ID (`COMMAND-12`) in the PR title, so GitHub links the PR and merging closes the issue.
- When you finish, pause or get blocked, comment on the issue: what changed, what actually passed, what remains. Tick only the "Done when" items you truly met; local checks don't satisfy items that ask for deployed or live evidence.
- File follow-ups you discover as new issues in the same project. Labels: `Bug`, `Feature`, `Improvement`, `Ops`, `Owner action` (needs Nicolas: accounts, terms, payments, decisions), `Waiting` (blocked on an outside party).
